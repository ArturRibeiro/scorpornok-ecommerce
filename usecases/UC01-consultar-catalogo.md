# UC01: Consultar catálogo

**Ator:** Cliente
**Objetivo:** Ver os produtos à venda para escolher o que comprar.

## Fluxo principal

1. O cliente acessa a loja.
2. O sistema exibe os produtos com nome, foto, descrição e preço.
3. O cliente navega pelas páginas do catálogo.

## Fluxos alternativos

- **2a. Nenhum produto cadastrado:** o sistema informa que o catálogo está vazio.

## Regras de negócio

- RN01: O catálogo é exibido em páginas de até 20 produtos.

## Pós-condição

O cliente conhece os produtos disponíveis e pode incluí-los no carrinho (UC02).
